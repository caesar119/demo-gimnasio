# demo-gimnasio

Demo sectorial de **Anett Digital**. Sitio estatico hecho con Astro + Tailwind.

- Publicado en GitHub Pages: https://caesar119.github.io/demo-gimnasio/
- Build para la raiz de un dominio: `npm ci && npm run build`
- Build para una subcarpeta: `ASTRO_BASE=/demo-gimnasio npm run build`

Para publicar en Vercel: importar este repositorio, framework Astro, sin variables de entorno.
